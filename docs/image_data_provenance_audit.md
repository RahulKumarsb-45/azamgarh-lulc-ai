## Executive Summary

This forensic audit investigates the provenance of every map, image, raster, and metric displayed across the 7-page interactive Streamlit dashboard. 

### Key Findings:
1. **The visible maps and images are 100% SYNTHETIC DEMONSTRATION DATA.** They are **not** real satellite photographs or classified Copernicus Sentinel-2 rasters.
2. **No user-supplied external satellite imagery was utilized.** The repository input folders (`data/raw/`, `data/labels/`, and `data/processed/`) contain only `.gitkeep` placeholder files.
3. **The project has NOT yet connected to live Google Earth Engine.** No `.env` credentials file exists in the repository, and no Earth Engine user tokens exist in `~/.config/earthengine/credentials`.
4. **Why images appear without an API key:** The dashboard does not call any remote satellite API at render time. It loads pre-generated local NumPy arrays (`.npy`), CSVs, and JSON files generated by the offline synthetic verification pipeline (`src/pipeline.py --mode synthetic`), and renders them in the browser using Plotly Express and Matplotlib.

## 2. Full Image-Generation Chain

The complete data provenance pipeline for every displayed map is:

```
[1. Fixture Generation]
src/data/synthetic_fixture.py :: generate_synthetic_study_area(grid_size=100, seed=42)
  │
  ├── Class 1 (Cropland ~74% background)
  ├── Class 2 (Vegetation patches along river & orchards)
  ├── Class 3 (Meandering Tamsa River feature: sin(c/8.0))
  ├── Class 4 (3 Urban settlement clusters: Azamgarh City & tehsils)
  └── Class 5 (Barren/open land patches ~3%)
  │
  └── Generates: class_grid_2019, class_grid_2022, class_grid_2025 (100x100 NumPy arrays)
         │
[2. Offline Pipeline Execution]
src/pipeline.py :: run_offline_synthetic_pipeline()
  │
  ├── Writes: data/outputs/classified/lulc_map_2019.npy, .tif
  ├── Writes: data/outputs/classified/lulc_map_2022.npy, .tif
  ├── Writes: data/outputs/classified/lulc_map_2025.npy, .tif
  ├── Simulates CA-Markov: predicted_map_2030.npy, predicted_map_2035.npy
  └── Writes Provenance Manifest: data/outputs/provenance.json ("is_synthetic": true)
         │
[3. Dashboard Data Loading]
dashboard/data_loader.py :: load_available_raster_maps()
  │
  ├── Reads data/outputs/provenance.json -> is_synthetic = True
  ├── Iterates over data/outputs/classified/*.npy and data/outputs/predictions/*.npy
  └── Loads arrays into memory: { 2019: {"data": ndarray, "is_synthetic": True}, ... }
         │
[4. Dashboard Image Rendering]
dashboard/pages/page2_maps.py :: render_maps_page()
  │
  ├── Retrieves raster array from dictionary (shape: 100 x 100)
  ├── Constructs discrete 5-class color mapping using CLASS_COLORS (#F2D16B, #2E7D32, #1E88E5, #D32F2F, #A1887F)
  └── Calls Plotly Express:
        fig = px.imshow(raster_data, color_continuous_scale=color_scale, range_color=[1, 5])
        st.plotly_chart(fig)
```

### Nature of the Displayed Image:
- It is **NOT** a satellite photograph or multi-spectral composite (such as True-Color RGB or False-Color NIR).
- It is a **categorical Land Use / Land Cover (LULC) map** showing classified discrete values (1 = Cropland, 2 = Vegetation, 3 = Water Bodies, 4 = Built-up, 5 = Barren).
- The numerical values originate **entirely from synthetic geometric simulation** (`src/data/synthetic_fixture.py`), not from Copernicus Sentinel-2 satellite sensors.

## 5. Why Does the Image Appear Without an API Key?

Users often wonder: *“How can the dashboard show a map of Azamgarh if I haven't entered my Google Earth Engine API key or Google Cloud Project ID?”*

### The Technical Explanation:
1. **Decoupled Architecture:** The dashboard (`dashboard/app.py`) is decoupled from the live satellite querying code (`src/data/gee_init.py` and `src/data/data_audit.py`).
2. **Local Caching:** When `page2_maps.py` renders, it calls `load_available_raster_maps()`. This function looks locally on your computer’s hard drive in `data/outputs/classified/` for files ending in `.npy`.
3. **Pre-Generated Verification Fixtures:** The repository includes offline synthetic arrays generated by `src/data/synthetic_fixture.py`. The pipeline executed offline, generated `lulc_map_2019.npy`, `lulc_map_2022.npy`, and `lulc_map_2025.npy`, and saved them to your local disk.
4. **Browser Rendering:** Streamlit simply reads the 100 × 100 numbers from your local `.npy` file, maps each number (1 to 5) to a hexadecimal color (`#F2D16B`, `#2E7D32`, `#1E88E5`, `#D32F2F`, `#A1887F`), and draws an interactive SVG/canvas heatmap in your browser via Plotly.
5. **No Network Call:** At no point during dashboard operation is any network request sent to Google Earth Engine or Copernicus Hub.
